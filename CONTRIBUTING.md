# Contributing to OpenBRCM

Thanks for helping! Please read [`docs/provenance.md`](docs/provenance.md) first —
this project has a strict clean-room policy.

## Developer Certificate of Origin
All commits must be signed off:

```
git commit -s
```

By signing off you certify the Developer Certificate of Origin v1.1 and that
your change does not copy code from the proprietary blob or other drivers.

## Coding style
Linux kernel style, enforced by `clang-format` (`.clang-format`) and
`checkpatch.pl`:
```sh
./scripts/check.sh
```
- tabs for indentation, 8 columns
- SPDX `GPL-2.0-only` header on every file
- no hand edits to generated headers (`src/ob_*.h` generated by `scripts/gen_headers.sh`)

## Building & testing
```sh
make            # build the module against the running kernel
make hosttest   # host unit tests for the pure math
```
For a KUnit-enabled build, add `tests/kunit/ob_math_kunit.c` per kernel docs.

## Pull requests
- one logical change per PR
- describe the milestone it advances (see `docs/milestones.md`)
- include the command output that demonstrates the gate where applicable
- update `docs/` if behaviour or interfaces change
- follow [`docs/github-workflow.md`](docs/github-workflow.md) for branching,
  commit format, review and release rules

## Reporting issues
Use the GitHub issue templates. For security, see [`SECURITY.md`](SECURITY.md).
